# OpenMedReason Bot demo

Interactive chat demo: pick a kind of medical image and a question, see how OpenMedReason (our 7B model trained to
reason about medical images) answers and explains itself, then compare it with the base model Qwen2.5-VL-7B on the
same image and question. Highlights mark what each model points at in the image (green), its conclusion (blue) and
mistakes (red, with a short note).

Live page: https://negiiiin.github.io/openmedreason-demo/

Images come from public research datasets (SLAKE, OmniMedVQA and its sources, FracAtlas, KAU-BCMD, CMMD, BUS-UCLM,
TN3K, Brain Stroke CT, BraTS 2023, GastroVision, CVC-ClinicDB, BBBC041). They are shown for research demonstration only
and remain under their original licenses. This page is not medical advice.
